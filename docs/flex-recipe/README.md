# Recette Symfony Flex

Squelette destiné à être soumis à
[`symfony/recipes-contrib`](https://github.com/symfony/recipes-contrib) sous
`zeggriim/youtrust-webhook-bundle/1.0/`.

Il configure le parser sur le composant Webhook, expose la route
`POST /webhook/yousign` et ajoute la variable d'environnement
`YOUTRUST_WEBHOOK_SECRET`.
